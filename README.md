# ℹ️ Sobre
Aplicativo de contador que permite aumentar, diminuir ou resetar o número exibido na tela. Feito usando HTML, CSS e JavaScript puros.

# 💡 O que aprendi fazendo isso
* Exercitei meus conhecimentos de CSS Flexbox
* Aprendi a usar a propriedade CSS **backdrop-filter** para aplicar efeito de blur em elementos
* Aprendi a fazer **animações** em CSS usando **@keyframes**. Animei o número na tela sempre que o usuário clica em um botão para deixar a página com uma aparência mais fluida
* Exercitei minha lógica de programação com JavaScript
